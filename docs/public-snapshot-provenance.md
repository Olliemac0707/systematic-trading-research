# Public-snapshot provenance

This repository is a curated public derivative of a separate private research system.
The private repository remains the authority for its original historical chain; the
public Git history is intentionally not presented as that original chain.

The public snapshot was created from a Git archive of that tag. Public-only changes
are limited to presentation, documentation, licensing, continuous integration,
line-ending portability and repository hygiene. The historical strategy, backtesting,
evaluation, experiment and result files were not reinterpreted as a new experiment.

## Deliberately excluded

- raw and prepared third-party market data;
- generated detailed research reports;
- credentials, local configuration and personal notes;
- later private research streams and execution-authority records; and
- every prospective-study protocol, state file and operational session artifact.

The omission of private history does not strengthen the research claim. The public
README and result record preserve the original negative generalisation conclusion.
